짧은 요약:
- 대탐험 서판(Expedition Precursor Tablet)은 접두사(범용 수량/희귀도)와 접미사(대탐험 전용 — 잔재물 드랍량 증가)로 나뉜다.
- 한 타워에 서판은 기본 **3장**까지 꽂을 수 있고, 특정 아틀라스 패시브를 찍고 **도시 지형(City Biome) 맵**에서는 **4장**까지 늘어난다. 수량·희귀도 계열 옵션은 여러 장 겹쳐도 그대로 누적된다.
- 반대로 "대탐험 등장" 같은 온/오프 방식 옵션은 같은 종류를 여러 장 꽂아도 중복 적용되지 않는다. 다른 종류의 서판(예: 대탐험+균열)을 같이 꽂는 건 가능하다.
- 정확한 옵션별 수치(%) 목록은 공식적으로 공개되지 않아 이 글에서 다루지 않는다. 접두사/접미사 구조와 중첩 규칙 위주로 정리했다.

| 접미사(Suffix) | 대탐험 전용 — 대탐험 몬스터의 잔재물(Artifact) 드랍량 증가 | 커뮤니티/가이드 |
| 타워당 서판 수 | 기본 3장, 도시 지형 맵 + 아틀라스 패시브로 4장까지 | 커뮤니티/가이드 |

| 등장 여부 중첩 | 같은 종류 여러 장이어도 중복 적용 안 됨 | 커뮤니티/가이드 |
| 고유 서판 | Forgotten By Time — 대탐험 몬스터 생명력 절반, 룬 몬스터 복제 | DB |

## 상세 설명

### 서판 구조 — 접두사와 접미사

서판에는 두 종류의 옵션이 붙는다. **접두사**는 서판 종류와 무관하게 공통으로 붙는 범용 옵션(아이템 수량/희귀도 등)이고, **접미사**는 서판 종류마다 다른 전용 옵션이다. 대탐험 서판의 접미사는 대탐험 몬스터가 드랍하는 잔재물(Artifact) 수량을 늘려주는 쪽으로 확인된다.

정확한 수치 구간이나 최상위 접미사가 뭔지는 POE2DB에도 가중치 정보가 공개돼 있지 않아 **확인하지 못했다**. 서판을 고를 때는 접두사(수량/희귀도)가 높은지, 접미사가 잔재물 관련인지 정도만 확인하는 걸 추천한다.

### 서판 여러 장 사용하기 — 중첩 규칙

한 타워에는 서판을 기본 **3장**까지 꽂을 수 있다(커뮤니티 가이드 기준). 이때:

- **수량·희귀도 계열은 그대로 누적된다.** 서판 여러 장의 수량 접두사를 합친 만큼 그 반경의 맵 전체에 적용된다.
- **"대탐험 등장" 같은 온/오프 옵션은 중복 적용되지 않는다.** 대탐험 서판을 여러 장 꽂는다고 대탐험이 그만큼 배로 많이 나오는 게 아니다.
- 대신 **서로 다른 종류의 서판을 섞어 꽂는 건 가능하다.** 예를 들어 대탐험 서판 + 균열 서판을 같이 꽂으면 그 반경 맵에서 두 콘텐츠가 함께 등장한다.

**4번째 슬롯**은 조건부로 열린다. 아틀라스 패시브 트리에서 타워 반경/서판 슬롯을 늘려주는 노드를 찍고, 그 타워가 **도시 지형(City Biome) 맵**일 때만 서판을 4장까지 꽂을 수 있다(복수의 커뮤니티 가이드로 교차 확인). 도시 지형이 아닌 일반 맵에서는 여전히 3장이 상한이다. 정확한 노드 이름의 한글 공식 표기는 확인하지 못해 기능 설명으로만 적었다.

### 고유 서판(Forgotten By Time)

일반 대탐험 서판과 별개로, 고유 서판 "Forgotten By Time"이 존재한다. 대탐험 몬스터가 생명력 절반 상태로 등장하고 룬 몬스터가 복제되는 효과다(POE2DB 확인). 일반 서판보다 극단적인 효과라 파밍보다는 특수한 상황에서 쓰인다.

### 경로석에 바르는 증류된 감정은 별개 시스템

서판과는 별개로, 경로석에 직접 바르는 소모성 재화인 증류된 감정(Distilled Emotion)도 대탐험 파밍과 자주 같이 언급된다. 이건 서판이 아니라 환영(Delirium) 계열 시스템이라 이 글에서는 다루지 않는다. 자세한 내용은 [POE2 0.5.5 파밍법 비교](/posts/poe2-0-5-5-farming-methods-comparison/) 글을 참고.

## 상황별 추천

- **타워 하나로 대탐험 파밍 루트를 짤 때**: 접두사(수량/희귀도) 위주로 채운다. 도시 지형 맵 + 해당 아틀라스 패시브가 있으면 4장까지 채울 수 있다.
- **다른 콘텐츠와 같이 굴릴 때**: 대탐험 서판 1~2장 + 다른 종류 서판을 섞어서, 온/오프 중복 낭비 없이 반경 안에 여러 콘텐츠를 동시에 띄운다.

## 주의점

- 접미사 옵션별 정확한 수치(%)는 공식적으로 공개된 자료를 찾지 못해 이 글에서 다루지 않았다.
- 4번째 슬롯 조건(아틀라스 패시브 + 도시 지형)은 복수 커뮤니티 가이드로 교차 확인했지만, 공식 패치노트로 재확인한 건 아니다. 해당 아틀라스 패시브의 정확한 한글 명칭도 확인하지 못했다.
- 이 글의 중첩 규칙은 커뮤니티 가이드 기준이며, 패치로 바뀔 수 있다.

## 3줄 요약

- 대탐험 서판은 범용 접두사(수량/희귀도)와 전용 접미사(잔재물 드랍량)로 구성된다.
- 타워당 기본 3장, 도시 지형 맵+아틀라스 패시브로 4장까지 가능하다. 수량·희귀도는 누적되지만 대탐험 등장 자체는 중복 적용되지 않는다.
- 정확한 옵션별 수치는 공식 자료가 없어 이 글에서 다루지 않았다.
