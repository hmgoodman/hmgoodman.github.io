짧은 요약:
- 스태시/서판 관리 창에 바로 붙여넣는 **전체 서판 통합 검색식**은 맨 위에 있다.
- 정규식에 걸린다고 **고가가 확정되는 게 아니다** — 후보를 빠르게 거르는 용도일 뿐이며, 실제 값어치는 반드시 거래소에서 따로 확인해야 한다.
- 대탐험 서판은 **추천 / 고가 후보** 2단계로 나눠서 쓰는 걸 권장한다.
- 이 글의 정규식·옵션명은 디시인사이드 원 게시물을 재구성한 것이며, 심연 서판 항목만 이전에 공식 패치노트로 교차 확인된 내용과 일치를 확인했다. 나머지는 커뮤니티 제보 수준이다.

## 전체 서판 통합 검색

```
정화.*희|유적.*룬|시물|묻힌|발굴.*희|헌정.*변|지하.*확|추가.*희귀|금고.*2개|등대.*고유|속성.*2개
```

7종 서판에서 "고가 후보"로 꼽히는 옵션 조각을 한 번에 훑는 압축형이다. 검색 결과가 많으면 아래 서판별 정규식으로 좁혀서 다시 본다.

## 한눈에 보기

| 서판 종류 | 검증 상태 |
|---|---|
| 균열(Breach) | 커뮤니티 제보 |
| 대탐험(Expedition) | 커뮤니티 제보 |
| 의식(Ritual) | 커뮤니티 제보 |
| 심연(Abyss) | 일부 공식 확인 (패치노트 교차 확인) |
| 감독관(Overseer) | 커뮤니티 제보 |
| 사원 | 커뮤니티 제보 — 서판 종류로서의 존재 자체도 확실치 않음 |
| 방사능 노출(Irradiated) | 커뮤니티 제보 |

## 서판별 정규식

### 균열 서판

```
정화.*희|균열.*효율|브룬|희귀.*몬
```

균열 관련 희귀 몬스터, 균열 효율 증가, 특정 균열 보스(브룬 계열) 등장을 겨냥한 조합이다. 정확히 어떤 옵션 문구에 걸리는지는 원문 기준으로만 확인했다.

### 대탐험 서판

대탐험은 정규식을 2단계로 나눠 쓰는 걸 권장한다. 넓게 거를 땐 추천, 좁혀서 고가만 볼 땐 고가 후보를 쓴다.

**추천 (넓게)**
```
혼.*추|험.몬|시물|묻힌|유적.*룬|일지|발굴.*희|복제
```

**고가 후보 (좁게)**
```
시물|묻힌|유적.*룬|발굴.*희|혼.*추
```

아즈메리 혼백류 증가, 발굴 관련 희귀 옵션, 유적/룬 관련 옵션을 겨냥한다. [대탐험 서판 옵션 우선순위](/posts/poe2-0-5-5-expedition-tablet-priority/) 글의 증류된 감정(Distilled Emotion) 관련 내용과 함께 보면 좋다.

### 의식 서판

```
헌정품.*변경|변경.*2|보류.*소모|변경.*소모
```

헌정품(Tribute) 무작위 변경, 소모 관련 옵션을 겨냥한다.

### 심연 서판

```
지하.*확|추가.*희|득시글|생성.*몬|구덩이.*보상
```

- `추가.*희` — [심연 추가 희귀 몬스터 생성](/posts/poe2-0-5-5-abyss-tablet-priority/) 옵션과 일치한다. 0.5.5 공식 패치노트로 확인된 항목('of Champions' 2~3마리 상향).
- `지하.*확` — 심연 몬스터가 심연 속성(Abyssal Modifier)을 가질 확률 증가 옵션으로 추정된다. 존재는 확인되지만 정확한 수치는 확실치 않음(이전 글과 동일).
- `구덩이.*보상` — 심연 구덩이 보상 관련 옵션으로 보이나, 정확한 효과는 확실치 않음.

### 감독관 서판

```
금고.*2개|금고.*1개|희귀.*몬|몬스터.*희귀|혼백.*2개
```

금고(Strongbox) 추가 생성, 희귀 몬스터 관련 옵션을 겨냥한다.

### 사원 서판

```
등대.*고유|등대.*무리|추가.*몬스터.*소환|수정.*추가
```

바알 등대(Lightless Reliquary 계열로 추정) 고유/무리 관련 옵션을 겨냥한다. 이 서판 종류 자체를 다른 출처로 명확히 교차 확인하지 못해 **확실치 않음**으로 남긴다.

### 방사능 노출 서판

```
속성.*2개|몬스터.*효율|몬스터.*희귀|금고.*확률
```

맵에 무작위 속성 추가, 몬스터 효율/희귀도 증가를 겨냥한다.

## 범용 좋은 옵션 정규식 (서판 종류 무관)

```
희귀.*몬|몬스터.*효율|몬스터.*희귀|속성.*2개|무리.*규모
```

서판 종류를 특정하지 않고, 어떤 서판이든 붙어 있으면 대체로 좋은 범용 옵션(희귀 몬스터, 몬스터 효율/희귀도, 무리 규모)만 걸러낸다. 종류별 정규식으로 후보를 못 찾았을 때 보조로 쓴다.

## 실전 사용법

1. 스태시 탭이나 서판 관리 창에서 검색창을 클릭(또는 `Ctrl+F`).
2. 위 "전체 서판 통합 검색" 정규식을 따옴표 없이 그대로 붙여넣는다.
3. 걸린 서판이 많으면 서판별 정규식으로 좁혀서 다시 검색한다.
4. 대탐험처럼 2단계가 있는 경우, 먼저 추천으로 넓게 훑고 고가 후보로 다시 좁힌다.
5. 최종 후보만 거래소(공식 trade site 또는 인게임 가격 확인)에서 실제 시세를 확인한다.

## 상황별 추천

- **처음 걸러볼 때**: 전체 서판 통합 검색으로 한 번에 훑는다.
- **특정 서판만 정리할 때**: 해당 서판의 정규식을 쓴다.
- **정규식으로도 안 걸리는데 뭔가 좋아 보일 때**: 범용 좋은 옵션 정규식으로 다시 확인한다.

## 주의점

- **정규식 매치는 고가 확정이 아니다.** 같은 옵션이라도 수치 구간, 다른 옵션과의 조합, 그날 시세에 따라 가격이 크게 달라진다.
- 이 글의 정규식과 옵션 설명은 디시인사이드 원 게시물을 재구성한 것으로, 심연 서판 항목 외에는 공식 패치노트로 교차 확인하지 못했다.
- "사원" 서판은 다른 출처에서 명확히 확인되지 않아 존재 자체를 확실치 않음으로 표시했다.
- 게임 내 옵션 문구가 패치로 바뀌면 정규식이 더 이상 매치되지 않을 수 있다.
- 정규식 검색창 글자 수 제한 등 기본 사용법은 [POE2 거래소/상점 정규식 사용법](/posts/poe2-trade-regex-guide/) 글을 참고.

## 3줄 요약

- 전체 서판 통합 검색식 하나로 1차로 고가 후보를 거르고, 서판별 정규식으로 좁힌다.
- 정규식은 후보를 거르는 도구일 뿐이며, 실제 시세는 반드시 거래소에서 확인해야 한다.
- 심연 서판 옵션 외에는 공식 확인이 안 된 커뮤니티 정보이므로 그대로 맹신하지 않는다.
