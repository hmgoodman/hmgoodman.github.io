POE2 고자본 맵핑 파밍 추천

짧은 요약: 자본이 충분하면 대탐험이 가장 높은 보상 기대치를 가진 콘텐츠로 언급된다(커뮤니티 제보). 고자본 구간에서는 서판 여러 장 + 고티어 경로석을 동시에 투입해 맵 하나의 밀도를 극대화하는 방식이 기본이다. 여러 메커니즘(심연+균열+환영 등)을 한 맵에 같이 굴리는 “올 메커니즘” 전략도 고자본에서 쓰인다(커뮤니티 제보). 한눈에 보기 전략 필요 조건 특징 대탐험 집중 탱키한 빌드, 로그북/서판 다량 확보 보상 기대치가 높다고 평가되지만 조작 난이도도 높음 고티어 T15+ 스피드 맵핑 클리어 속도 빠른 빌드, 고배율 경로석 시간당 회전수로 수익을 뽑는 방식 올 메커니즘 파밍 여러 서판 동시 투입 가능한 자본 한 맵에서 여러 콘텐츠 보상을 동시에 수령 상세 설명 대탐험 집중 대탐험은 로그북과 서판을 갖추고 몬스터 효과·희귀도가 높은 맵에서 진행할수록 보상 기대치가 커진다고 알려져 있다(커뮤니티 제보). 0.5.5부터 대탐험 콘텐츠가 스탠다드 리그를 포함해 코어 메커니즘으로 전환됐다(공식 패치노트). 다만 기폭 위치·타이밍을 스스로 계산해야 하고, 고배율 맵은 몬스터도 강해지므로 탱키한 빌드가 전제조건이다. ...
