POE2 0.5.5 파밍법 비교 - 심연 / 대탐험 / 의식 / 브리치 / 딜리리움

짧은 요약: 진입 장벽이 가장 낮은 건 브리치, 요구 스펙이 가장 높은 건 대탐험이다. 초보는 브리치 → 심연/딜리리움 → (스펙 갖춘 뒤) 대탐험 순으로 넘어가는 걸 추천. 의식은 현재 니치 전략으로 분류되는 경우가 많다(오멘 시세에 좌우됨). 정확한 시간당 수익 수치는 빌드·숙련도·시세에 따라 편차가 커서 이 글에는 넣지 않았다. 한눈에 보기 콘텐츠 준비물 조작 난이도 초보 적합도 브리치 브리치 서판 낮음 — 균열 안정화 후 처치만 하면 됨 좋음 심연 심연 서판 낮음~중간 — 균열 따라 이동, 반복 클리어 좋음 딜리리움 딜리리움 서판 중간 — 안개 범위 안에서 몬스터 처치 유지 괜찮음 (극한 장비 불필요) 의식 제단 방어용 빌드 중간 — 몬스터 웨이브 동안 제단 사수 시세 의존적, 초보에겐 애매 대탐험 로그북/서판, 탱키한 빌드 높음 — 기폭 타이밍·위치 계산 필요 비추천(선딜/저스펙 위험) 상세 설명 브리치 서판(하이블러드 계열) 몇 장만 있어도 굴릴 수 있어 진입 장벽이 낮다고 평가된다(커뮤니티 제보). 0.5.5에서 불안정 균열을 안정화하면 희귀 몬스터가 한 번에 다 나오지 않고 5마리씩 웨이브로 등장하도록 바뀌어, 순간 물몸이 몰리는 위험이 줄었다(공식 패치노트). ...
